# Bank Branches Profit Analysis 📊

A C# Windows Forms application for analyzing monthly profits of five bank branches.

The application compares profits from two services: deposits and credits, and displays the results using a column chart and a data table.

## About the Project

The application allows the user to enter monthly profit values for five bank branches.

For each branch, two types of services are analyzed:

- Deposits
- Credits

The entered data is stored in arrays and displayed in a chart and a DataGridView table.

The application also performs additional calculations to analyze the differences between deposits and credits.

## Features

- Input profit data for 5 bank branches
- Separate data for deposits and credits
- Store data in arrays
- Display profits using a column chart
- Display two chart series
- Show values directly on the chart
- Display all data in a DataGridView table
- Find the branch with the maximum profit difference
- Find the branch with the minimum profit difference
- Calculate the average total profit of all branches
